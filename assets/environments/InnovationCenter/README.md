# MSOE Innovation Center

The MSOE Innovation Center is a multi-story engineering facility on the Milwaukee School of Engineering campus. It is the target environment for the BIM-to-Sim navigation research project — robots are trained in simulation on this building's digital twin before being deployed in the physical space.

## Structure

The building has **4 above-ground floors** that are relevant for robot navigation:

| Floor | Description | Z (m) | Area (m²) |
|-------|-------------|-------|-----------|
| 1 | Ground level | 14.0 – 16.0 | ~4,746 |
| 2 | Second floor | 19.5 – 20.5 | ~4,401 |
| 3 | Third floor | 23.5 – 24.5 | ~4,379 |
| 4 | Fourth floor | 27.5 – 29.0 | ~4,208 |

Floor spacing is uneven — Floor 1 → 2 is 5.5m (higher ceiling on the ground level, typical for open/event spaces), and Floors 2 → 4 are spaced 4.0m apart.

## Coordinate System

The building USD uses **meters** as its base unit (`metersPerUnit = 1.0`), inherited from the Revit export. The world frame X and Y lie in the horizontal plane; Z is vertical. The origin is not colocated with any particular floor corner — it comes directly from the Revit model.

All occupancy maps, navigation graphs, and floor bounds in this project are expressed in this same frame, so coordinates can be used interchangeably between the USD scene and the nav data.

## USD Files

- `InnovationCenter.usd` — The primary Innovation Center model (raw Revit export).
- `../final_building_msoe/FinalMSOEBuildingV4_physics.usd` — Physics-processed version (colliders, door joints, materials) used for robot simulation. Loaded by the Nova Carter navigation scripts.

## Navigation Assets

Each floor has a pre-generated occupancy map and navigation graph. Paths are recorded in `building_info.json` alongside this README.

**Occupancy maps** (`assets/environments/InnovationCenter/maps/`):
- `floor_{1-4}_occupancy.png` — ROS `map_server`-compatible 8-bit grayscale (white=free, black=wall, gray=unknown)
- `floor_{1-4}_occupancy.npy` — NumPy array version (0=free, 1=occupied, 2=unknown)
- `floor_{1-4}_meta.json` — Scan parameters: Z range, world bounds, resolution

All floors are at **5 cm/pixel** resolution.

**Navigation graphs** (`assets/environments/InnovationCenter/navgraphs/`):
- `floor_{1-4}_auto_navgraph.json` — Nodes (world XY, grid RC) + edges (distance in meters)
- `floor_{1-4}_auto_navgraph.gml` — NetworkX format
- `floor_{1-4}_map_metadata.yaml` — ROS `map_server` YAML (resolution, origin, thresholds)
- `floor_{1-4}_auto_navgraph.png` — Visual overlay (cyan edges, red nodes)

| Floor | Nodes | Edges |
|-------|-------|-------|
| 1 | 292 | 301 |
| 2 | 388 | 391 |
| 3 | 342 | 344 |
| 4 | 232 | 239 |

Graphs were generated by `floorplan_vision/auto_graph_generator.py` using medial-axis skeletonization with 0.36m robot safety clearance and 2m waypoint spacing.

## How the Data Was Generated

1. **Revit → USD**: Architectural BIM model exported to USD via Omniverse.
2. **Physics Pipeline** (`sim_utils/building_physics.py`): Applies colliders to structural elements, door hinges with `DriveAPI`, materials, and collision filters. Outputs `*_physics.usd`.
3. **Floor Scanning** (`floorplan_vision/generate_occupancy_map.py`): Runs Isaac Sim headlessly, raycasts at robot scan height (1.4m above the floor deck) across a 2D grid, writes occupancy `.npy` + `.png` + `meta.json` to `assets/environments/InnovationCenter/maps/`.
4. **Graph Extraction** (`floorplan_vision/auto_graph_generator.py`): Skeletonizes the free space, detects junctions and endpoints, samples waypoints, exports JSON/GML/YAML.
